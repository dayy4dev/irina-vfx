IrinaFX

Seventeen ordinary controls that react like anime: squash and overshoot on springs, and drawn effects (smoke, impact bursts, splashes, slashes) with manga sound-effect lettering. Each one is a single file with no dependencies.

Theme:

Updates both CSS --ir-* variables and Canvas IrinaFX.P live. (<irina-toggle> uses a pre-painted sprite sheet.)

Effects are drawn on one canvas over the page. By default, animations stay active even if Windows disables animations (prefers-reduced-motion); use the toggle above to follow the OS setting. Every colour is a --ir-* variable you can override.
